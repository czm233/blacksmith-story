# 《铁匠物语：工匠与商会》Web 3D MVP

> 基于 Three.js + React 19 + TypeScript + Tailwind CSS 的工匠经营与 3D 装配锻造 Web 游戏

---

## 🌟 核心特性与技术实现

### 1. 核心玩法与经营全闭环
* **本地商会统购包销**：商会平价供给橡木条 ($3)、生铁锭 ($5)、精钢锭 ($15) 与入门图纸；无拒收统购回收全部成品武器，秒结金币。
* **图纸即骨架（Blueprint as Scaffold）**：图纸定义插槽树拓扑规范，从学徒级的 2 部件到神兵级的 5 部件深度渐进演化。
* **打铁精准敲击小游戏**：在游标划过金色完美区时敲下铁锤，3 锤定级，决定【普通 / 良品 / 极品 / 传世】品级与高达 2.2 倍的回收溢价。
* **灵光一闪（Epiphany）顿悟机制**：在日复一日的锻造敲击中，依据概率（12%、3%、0.3%）触发灵光一闪，自动领悟高阶图纸并伴随圣光与礼炮特效。
* **云游商人（Wandering Merchant）巡回**：周期性到访工坊门前（90 秒循环，停留 45 秒），兜售稀世星陨石 ($60) 与神兵图纸秘卷。
* **试刀木桩与打击顿帧**：将锻造完成的武器斩击训练木桩，伴随 GSAP 弹性阻尼回弹、飞溅火花与浮动暴击伤害跳字。

## 📐 3D 几何与挂点协议（Socket Protocol）

采用局部坐标系相对吸附，保证任意部件在代码层完全解耦：

```text
[ 叶节点: 剑身 Blade ] ── 原点位于底座截面中心，向上延伸 0.8~1.4m
         ▲
         │ (吸附至 Socket_Blade)
[ 中继件: 护手 Guard ] ── 原点位于底座，顶端提供挂点 Socket_Blade (y = +0.05m)
         ▲
         │ (吸附至 Socket_Guard)
[ 根节点: 握柄 Grip  ] ── 原点 (0, 0, 0) 位于手握持受力点，顶端提供 Socket_Guard (y = +0.22m)
```

* **白色图纸特化处理（Socket Fallback）**：白色图纸不声明 `Guard` 槽位，`Blade` 挂载点自动降级回退至握柄的 `Socket_Guard`，组装引擎保持完全统一。
* **高阶扩展插槽**：
  * `Socket_Pommel` (y = -0.12m)：加装配重球或龙纹配重。
  * `Socket_Gem` (y = +0.02m, z = +0.035m)：加装炽火熔岩星核宝石槽。

## 🚀 启动与运行

```bash
# 进入项目目录
cd /Users/zemingchen/githubProjects/blacksmith-story

# 安装依赖（已预先安装）
npm install

# 启动本地开发服务 (默认端口 3000)
npm run dev

# 编译生产打包
npm run build

# 预览生产版本
npm run preview
```

## 🎮 操作控制与快捷键

* **鼠标左键拖拽**：360° 全方位自由旋转武器视角。
* **鼠标滚轮**：平滑拉近/推远镜头。
* **空格键 (Space)** 或点击按钮：在精准锻造小游戏中挥锤敲击。
* **顶栏工具按钮**：开关自动旋转、视角复位、特写剑刃/护手、显示 3D 插槽挂点标记球。
* **左侧交付按钮**：点击一键交付商会，即刻领取现款金币。
* **试刀按钮**：点击试刀斩击木桩，测试真实暴击与物理打击感。
